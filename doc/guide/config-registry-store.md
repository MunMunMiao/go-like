# Config, registry, cache, and store

These four domains are related operationally, but they are not interchangeable. `@likego/config` merges sources into immutable, last-good snapshots and owns accepted watchers. `@likego/registry` publishes service nodes and discovers live endpoints. `@likego/cache` provides disposable Context-first byte values with optional TTL, while `@likego/store` provides durable byte records with revisions, TTL, CAS, prefix reads, and stable pagination.

Configuration sources include injected environment values and files, Consul, etcd, Kubernetes ConfigMap/Secret through `@likego/config-kubernetes`, and Vault KV v2 through `@likego/config-vault`. Registry providers include mDNS for local networks, Consul, etcd, Kubernetes EndpointSlice, and ZooKeeper. Cache implementations are split into `@likego/cache-memory` and `@likego/cache-redis`. Store providers include a single-owner file snapshot, Consul KV, etcd KV, and Vault KV v2 through `@likego/store-vault`. Each provider lives in its own flat package, so an application pays only for its chosen backend.

Provider constructors take explicit addresses, credentials, and host capabilities. Portable HTTP providers receive a one-argument Fetch function instead of reading runtime globals. Credentials stay in headers and must not appear in public error text. Watch implementations recover from backend-specific gaps—such as an etcd compaction or Kubernetes `410 Gone`—by taking a fresh snapshot before resuming. ZooKeeper watches likewise re-arm after one-shot delivery or session expiry. If cancellation arrives after a `multi` submission, the provider waits for the real result and rolls back the exact state; if the outcome remains ambiguous, it closes the session and restores any previously accepted registration owners.

Treat the file store as small local state, not a multi-process database. Treat registry data as ephemeral reachability, not durable business storage. Those boundaries prevent convenient-looking APIs from quietly promising guarantees their backends do not have.
