# LikeGo

LikeGo مجموعة من لبنات البناء الصغيرة، المصممة بأسلوب Go لخدمات الخلفية المكتوبة بـ TypeScript. تمنح التطبيق عقوداً صريحة لدورة الحياة، وإلغاء العمل عبر `Context`، واستدعاءات الخدمات، واكتشافها، والرسائل، والإعدادات، والتخزين، وفحوص الصحة، والقياس التشغيلي، من دون أن تفرض عليه إطار عمل أو بيئة تشغيل بعينها.

تلتزم الشيفرة القابلة للنقل بواجهات Web القياسية مثل `Request` و`Response` و`Headers` و`AbortSignal` وWeb Streams ودالة `fetch` المحقونة. أما ما يرتبط ببيئة تشغيل محددة فيبقى داخل حزمة أو مسار فرعي مستقل. لذلك تستطيع الاستمرار في استخدام Hono أو Elysia أو H3 أو Croner أو BullMQ أو NATS أو Pino أو Winston، بل وحتى خادم من تصميمك، ثم تكييف دورة حياته فقط مع LikeGo.

ابدأ بصفحة [البدء](/ar-Arab/guide/getting-started)، ثم اقرأ [البنية](/ar-Arab/guide/architecture) قبل اختيار المزوّدات. يوضّح [مرجع الحزم](/ar-Arab/reference/packages) الجهة المسؤولة عن كل قدرة، بينما تميّز صفحة [التحقق](/ar-Arab/reference/verification) بين ما اختُبر فعلياً وما قد يبدو ممكناً نظرياً فحسب.

## ما المقصود بأسلوب Go هنا؟

يأتي `Context` أول وسيط في كل عملية قد تنتظر، وتظل ملكية الموارد ظاهرة، ويكون للإيقاف ناتج نهائي قابل للملاحظة، وتُلبّى الواجهات الصغيرة بنيوياً. لا يعني ذلك نسخ طريقة تسمية Go أو الادعاء بأن JavaScript يملك goroutines وchannels؛ تبقى صادرات TypeScript طبيعية، وتظل كائنات المزوّد الأصلية متاحة عندما لا تستطيع واجهة مشتركة تمثيل سلوكها بأمانة.
